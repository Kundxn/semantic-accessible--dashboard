# Semantic HTML5 & Accessible Component Architecture

This repository contains the semantic HTML5 layout and WCAG 2.1 AA accessible component architecture for an enterprise dashboard.

## Features
- **Semantic Structure**: Proper usage of `<header>`, `<nav>`, `<aside>`, `<main>`, `<article>`, and `<footer>` HTML5 elements.
- **WCAG 2.1 AA Compliant**: Includes standard ARIA roles, form labels, target input associations, skip-navigation link, and keyboard-accessible modal structure.
- **W3C Validated**: Valid HTML5 markup free of syntax errors.

## Usage
Simply extract `index.html` and open it in any web browser.
